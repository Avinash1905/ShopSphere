# ShopSphere Deployment Guide

## Prerequisites
- Node.js >= 18.0.0
- npm >= 9.0.0

## Local Development
```bash
# Start frontend
npm run dev

# Run LOC analysis
npm run count:loc

# Run test suites
npm run test

# Build production bundle
npm run build

# Package TrainPlex zip archive
npm run package:trainplex
```
